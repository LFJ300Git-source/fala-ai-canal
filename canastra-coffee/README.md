# Canastra Coffee

Luxury gourmet coffee brand website with scroll-driven cinematic narrative.

## Local Development

```bash
npm install
npm start
# → http://localhost:3000
```

## Deploy to Vercel

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new)

1. Push this repo to GitHub
2. Import on vercel.com → select the repo
3. **Framework Preset**: Other  
4. **Root Directory**: leave as `/`  
5. **Build Command**: leave empty  
6. **Output Directory**: `public`  
7. Click **Deploy**

> Note: the video file (`public/video/main.mp4`) must be committed to the repo or hosted on a CDN and referenced via an absolute URL in `index.html`.
